# Inbox API

The inbox aggregates items needing attention: session continuations, auth results, work units, open issues, and webhook events. Agents query the inbox at session start to pick up pending work.

## Endpoints

### GET /api/inbox

Get pending inbox items, optionally filtered by branch and repo.

**Query params:**

| Param | Type | Description |
|---|---|---|
| `branch` | string | Filter by git branch |
| `repo` | string | Filter by repository path or name |
| `session_id` | string | Exclude continuations from this session |

**Response:** `200 OK`

### GET /api/inbox/global

Get all unacknowledged items across all branches and repos. Same response shape as `/api/inbox` but with additional fields:

- Continuations include `repo` (derived from cwd)
- Auth results include `repo` and `base_branch`
- Open issues include `repo_id` and `repo_name`

```bash
curl http://localhost:19420/api/inbox/global
```

### POST /api/inbox/:type/:id/ack

Acknowledge an inbox item.

**Path params:**

| Param | Values | Description |
|---|---|---|
| `type` | `continuation`, `auth_result` | Item type |
| `id` | string | Item ID (supports prefix matching) |

**Request body:**

| Field | Type | Description |
|---|---|---|
| `session_id` | string | ID of the acknowledging session |

**Response:** `200 OK`

```json
{ "ok": true }
```

**Error responses:**
- `400` — Invalid type
- `404` — Not found or already acknowledged
- `409` — Ambiguous prefix

```bash
curl -X POST http://localhost:19420/api/inbox/continuation/abc123/ack \
  -H 'Content-Type: application/json' \
  -d '{"session_id": "my-session-id"}'
```

### POST /api/inbox/ack-all

Acknowledge all unacknowledged continuations and auth results at once.

**Response:** `200 OK`

```json
{ "ok": true }
```
