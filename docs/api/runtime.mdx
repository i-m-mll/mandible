# Runtime API

The runtime API manages Zone 2 (self-updating clone) lifecycle. Zone 2 is a separate git clone that Mandible can update independently from the main development worktree.

## Endpoints

### GET /api/runtime/status

Get current Zone 2 runtime status.

**Response:** `200 OK`

```json
{
  "zone2_path": "/path/to/zone2",
  "exists": true,
  "branch": "main",
  "commit": "abc1234",
  "behind_upstream": 0,
  "patches_applied": 2,
  "last_updated": "2025-03-20T10:30:00Z"
}
```

### GET /api/runtime/patches

List recorded patches applied to Zone 2.

**Response:** `200 OK` — array of patch records.

### POST /api/runtime/bootstrap

Trigger Zone 2 clone (runs asynchronously). Returns immediately; check status via `/api/runtime/status`.

**Response:** `200 OK`

```json
{ "ok": true, "message": "Bootstrap started" }
```

### POST /api/runtime/update

Check for upstream updates and apply if available.

**Response:** `200 OK`

```json
{ "ok": true, "updated": true, "behindBy": 3, "status": { ... } }
```

Returns `{ "updated": false, "message": "Already up to date" }` when no updates are available.

### POST /api/runtime/rollback

Revert the last applied patch.

**Response:** `200 OK`

```json
{ "ok": true, "status": { ... } }
```

### POST /api/runtime/reset

Reset Zone 2 to match upstream main (discards all local patches).

**Response:** `200 OK`

```json
{ "ok": true, "status": { ... } }
```
