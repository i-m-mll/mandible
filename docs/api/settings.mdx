# Settings API

Key-value settings stored in the Mandible database. Settings control daemon behavior, UI preferences, and backup scheduling.

## Endpoints

### GET /api/settings

Get all settings as a key-value object.

**Response:** `200 OK`

```json
{
  "theme": "dark",
  "protected_branches": "main,develop",
  "backup.enabled": "true",
  "backup.interval_hours": "6",
  "backup.destination": "/Users/user/.mandible/backups/mandible-metadata.sql"
}
```

```bash
curl http://localhost:19420/api/settings
```

### GET /api/settings/:key

Get a single setting value.

**Response:** `200 OK`

```json
{ "key": "theme", "value": "dark" }
```

**Error:** `404` if the key does not exist.

```bash
curl http://localhost:19420/api/settings/theme
```

### PUT /api/settings/:key

Create or update a setting. All values are stored as strings.

**Request body:**

| Field | Type | Required | Description |
|---|---|---|---|
| `value` | string | yes | Setting value |

**Response:** `200 OK`

```json
{ "ok": true, "key": "theme", "value": "dark" }
```

**Side effects:**

- **Tier 2 settings** (`theme`, `prompt`, `multiplexer`): also written to `~/.config/dotfiles.conf` as environment variables.
- Legacy `reaper_*` settings may still be present in older databases and remain writable for compatibility, but Mandible no longer mirrors them to `~/.config/claude-reaper/config` or manages the standalone Reaper launchd job.

```bash
curl -X PUT http://localhost:19420/api/settings/theme \
  -H 'Content-Type: application/json' \
  -d '{"value": "dark"}'
```

## Known Setting Keys

| Key | Default | Description |
|---|---|---|
| `theme` | — | UI theme |
| `prompt` | — | Shell prompt style |
| `multiplexer` | — | Preferred multiplexer |
| `protected_branches` | `main,develop` | Comma-separated list of protected branches |
| `backup.enabled` | `true` | Enable scheduled backups |
| `backup.interval_hours` | `6` | Hours between backups |
| `backup.destination` | Mandible data directory | Metadata backup output file |
| `console_pinned_sessions` | `[]` | JSON array of pinned console session IDs |
