## Substantial improvements prepared

### Conversation source demand and search availability

Selected Chat reads strengthen one canonical logical-source ingestion demand.
Pending and running demand preserve priority and freshness, and background work
services selected reads at safe source boundaries through one serialized writer.
A generation guard prevents an older freshness observation from satisfying later
demand. This removes the competing promise and request ownership behind
[issue:782a50e].

Cold full-text search uses the existing logical-source representation boundary,
finds compressed-only transcripts, and does not cache unavailable content as a
complete empty result. Restoring source bytes recovers without reingestion
([issue:08ea52f]). The integrated source candidate passes 91 focused tests,
static checks and build, with Astra review and exact runtime acceptance.

Isolated checks do not prove corpus completeness. The corrected source/search
candidate [auth:6bab73d4] includes shared readiness classification and repair
scheduling for old parser/normalization epochs, including unchanged file mtime.
Unsupported or unavailable source coverage is explicit rather than silently
omitted. Withdrawn source requests are not approval dependencies.

### Verified asynchronous full-text search

One verified masked-block reader stops at the first exact match and requires
verified exhaustion for no-match. Search jobs return pending before corpus
preparation and publish exact totals/pages only for complete coverage. Pages
retain a pinned logical snapshot and verify displayed sources without rereading
the corpus. The client keeps its labeled last complete results until a complete
replacement arrives. No corpus-sized second body index is added.

Safe append continuation and complete prefix-plus-tail navigation are established
before native payload promotion. Failed promotion retains legacy tail data. These
contracts were repaired after the combined full gate exposed failures missed by
the focused suite.

An isolated 297-source Gemini workload completed with zero coverage failures.
Twenty first-pending HTTP responses had p95 0.642 ms; 72 status responses had p95
17.909 ms. These are bounded local socket measurements, not production or
whole-corpus latency. The full copied dataset returned explicit incomplete state
because a required native Claude source file was absent; it published no false
totals. Evidence: [artifact-version:1aa953464cd5].

### Live detail reconciliation and cancellation

Mounted Graph/Spaces issue details and both artifact entry points share Query
resource identity and event reconciliation. Publication preserves coherent
content while waiting or failing, along with explicit pins, drafts, scroll and
hidden-view intent. The displaced detail hook and duplicated artifact lifecycles
are removed ([issue:08b19dc]), advancing [issue:4eee711].

Cancelling the final cached GET consumer retires its request synchronously; a
replacement cannot join an aborted request, and a late completion cannot replace
new data ([issue:f0a9740]). Static/type checks, 19 targeted behavior checks,
planner review and exact runtime acceptance pass.

### Project merge integrity

One schema-backed typed policy classifies project references as move, merge or
pin, including differently named foreign keys and typed embedded/repository
locators. Immutable authority and custody references block incompatible changes.
Identical grants coalesce while distinct roles remain independently revocable.
Restricted-setting conflicts block rather than silently change authority.

Repair, key backfill and events commit atomically under foreign-key enforcement
without treating unrelated pre-existing orphans as newly introduced defects.
Historical repository probes run asynchronously outside the transaction, whose
observations are revalidated before committing. A reported 25-path reproduction
reduced a 209 ms blocked turn to a 7.1 ms maximum interval. Focused checks,
static/type checks, planner review and exact runtime acceptance pass
([issue:c58f752], [issue:955ac64]).

### Authority resource lifetime

Shutdown joins clearance admission, signer borrows, binding retirement and database
lifetime. Executor timeout waits for owned descendants before releasing authority.
If termination cannot be proved, the request and repository remain nonterminal,
the signer remains borrowed, and shutdown reports failure for explicit recovery.
Retryable drain/restart and exact process/socket identity preserve ownership.
Approval cancellation is registered before asynchronous admission checks.

The authority candidate passes build, static/type checks, planner adversarial
review and exact candidate acceptance. Its code-equivalent full gate passes 423
files and 2,960 tests. Unproven termination has no automatic proof-retry handle;
abrupt crashes and surviving borrowers need a separate durable-identity design.
