# Agent integration

Mandible can work with managed and external agent sessions. The connection
method determines which process controls and data are available; it does not
rank agents or change the distinction between authorship, responsibility, and
permission described in [Architecture](/docs/concepts/architecture).

- **Console SDK sessions** run through the Claude Agent SDK and expose structured
  events and SDK lifecycle controls.
- **Console PTY sessions** run commands in a pseudo-terminal and provide terminal
  I/O and process controls.
- **Channel connections** give an external Claude session Mandible tools and
  notifications without making Mandible the process owner.
- **External sessions** can be discovered from provider-native conversations.
  Hooks or `mandible wrap` may also register process and navigation information.

All of these can participate in work through the applicable Mandible interfaces.
Provider-native files remain the source of conversation text regardless of how a
session was launched. See [Conversations](/docs/features/conversations) and
[Agent integration setup](/docs/getting-started/agent-integration).
