# Other Features

- **Header icon modes** — switch header tabs between text labels, icons, or both (Settings > Appearance > Header tabs).
- **Breadcrumb toggle** — Convention Library cards can show ancestor breadcrumbs; toggle via the checkbox in the library header.
- **PTY banner** — PTY-backed console sessions display a deprecation notice recommending SDK sessions for full feature integration.
