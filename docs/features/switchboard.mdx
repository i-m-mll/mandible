# Switchboard

The Switchboard manages **symlink pairings** — named mappings between a source directory and a target directory. For each item (file or subdirectory) in the source, you can toggle whether a symlink exists at the corresponding path in the target. This is useful for selectively linking dotfiles, config snippets, plugin directories, or any other set of files that need to appear in multiple locations.

## Concepts

A **pairing** has:

- **Name** — a human-readable identifier (e.g., "neovim plugins").
- **Source** — the directory containing the canonical files.
- **Target** — the directory where symlinks should appear.
- **Lifecycle hooks** (optional) — shell commands run after linking (setup) or unlinking (teardown) an item.

Each item in the source can be in one of four states:

| State | Meaning |
|-------|---------|
| **linked** | A symlink exists at the target path pointing to the source. |
| **unlinked** | No symlink exists; the item is only in the source. |
| **broken** | A symlink exists but points to a missing target. |
| **conflict** | A real file (not a symlink) exists at the target path. Cannot be toggled — resolve manually. |

## Layout

Left panel lists pairings; right panel shows the items for the selected pairing.

### Creating a pairing

Fill in the name, source path, and target path in the form at the bottom of the left panel, then click **Add**. Optionally expand the **Advanced** section to configure lifecycle hooks or apply a hook template.

### Managing items

Select a pairing to see its items. Click any item row to toggle it between linked and unlinked. The toggle runs the appropriate lifecycle hook if one is configured.

The **Sync** button re-scans the source directory and reconciles the link state — useful after manual filesystem changes.

### Hook templates

Hook templates are reusable setup/teardown scripts. Apply a built-in or custom template from the Advanced section, or save the current hooks as a new template with **Save as template**.

### Editing and deleting

Click a pairing to enter edit mode — the form pre-fills with its current values. Update source, target, or hooks and click **Update Pairing**. Delete via the ellipsis menu on the pairing card.

## Summary

A status summary at the bottom of the items list shows counts by state (e.g., "12 linked, 3 unlinked, 1 broken").

## Consistency errors

If a lifecycle hook fails during the initial scan, the error is shown at the bottom of the items panel. This typically means the hook script has a syntax error or references a missing command.
