# Settings

The Settings tab exposes all of Mandible's configurable options, organized into sections. Changes take effect immediately unless noted otherwise.

## Notifications

Desktop alerts for agent tools.

| Setting | Type | Description |
|---------|------|-------------|
| Claude notifications | Toggle | Show a macOS notification when Claude Code stops and is waiting for input. |
| Codex notifications | Toggle | Same, for Codex CLI. |
| Sound | Select | macOS system sound to play with notifications. Options: Blow, Glass, Ping, Pop, Purr, Sosumi, Submarine, Tink. |
| Quiet hours | Text | Suppress notifications during a time window (format: `HH:MM-HH:MM`, e.g., `22:00-08:00`). |

## Mandible Daemon

Only visible when running inside the desktop app (Tauri shell). See [Desktop App](/docs/guides/desktop-app) for details.

| Setting | Type | Description |
|---------|------|-------------|
| Launch mode | Select | `on_demand` starts the daemon automatically when the app opens. `manual` leaves it stopped until you start it explicitly. |
| Start / Restart / Stop | Buttons | Direct lifecycle control over the daemon process. |

## Process Management

The standalone Claude/Codex Reaper integration is deprecated. Mandible still reconciles dead sessions internally, but Reaper-specific settings are no longer shown in Settings and are no longer dual-written to `~/.config/claude-reaper/config`.

## Agent Hooks

| Setting | Type | Description |
|---------|------|-------------|
| PreToolUse hooks | Toggle | Safety hooks that block dangerous git operations (merge into protected branch, raw commit without `commit-linked`, etc.). Disabling removes safety guards. |
| Subagent panes | Toggle | Spawn Zellij panes for subagent output streams. Requires Zellij and the `zj-control` plugin. |

## Conversation Branching

| Setting | Type | Description |
|---------|------|-------------|
| Resume conflict policy | Select | What happens when you resume a conversation that's already active in Console. Options: *Ask me each time* (prompt), *Auto-fork* (create a new branch), *Allow concurrent* (resume in-place). |

## Work Queue

| Setting | Type | Description |
|---------|------|-------------|
| Auto-resume policy | Select | How to handle work-unit continuations. Currently only *Manual* (user clicks Resume from the Inbox or Issues tab). |

## Appearance

These settings affect the shell environment, not the dashboard itself. Changes require a new shell session.

| Setting | Type | Description |
|---------|------|-------------|
| Header tabs | Select | Show text labels, icons, or both in dashboard header tabs. Takes effect immediately. |
| Theme | Select | Color theme applied to Neovim, Zellij, and tmux. Options include Catppuccin variants, Tokyo Night, Gruvbox, Nord. |
| Prompt | Select | Shell prompt engine: powerlevel10k or starship. |
| Multiplexer | Select | Terminal multiplexer preference: zellij, tmux, both, or none. |

## Version Control

| Setting | Type | Description |
|---------|------|-------------|
| Protected branches | Text | Comma-separated branch names pinned in the Work tab and used as the baseline for ahead/behind counts (e.g., `main, develop`). |

## Maintenance

| Setting | Type | Description |
|---------|------|-------------|
| Log retention | Number (days) | How many days to keep Mandible logs. Range: 1-365. |

## Backup

Automatic metadata dumps to the configured Mandible backup file.

| Setting | Type | Description |
|---------|------|-------------|
| Automatic backup | Toggle | Run Mandible's in-process metadata dump on a schedule. |
| Interval | Select | 6h, 12h, or 24h. |
| Destination | Text | Output path for the metadata dump. |
| Run Now | Button | Trigger an immediate backup. |

Status shows when the last backup ran and its file size.

Restore is deferred until Mandible has a tested restore round trip.
