# Issue-aware commits

`commit-linked` is a dotfiles policy wrapper. Mandible supplies issue-file,
issue-title, session-link, and work-unit APIs. The wrapper owns staging,
signing, commit prose, and attribution.

Issue associations live in structured ledger records. Commit messages have no
issue-linking or closure semantics. Use explicit issue references with auth
requests and explicit closure actions when a successful merge should close an
issue. Ordinary Git commits do not require Mandible metadata in their messages.
