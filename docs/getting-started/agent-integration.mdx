# Agent integration

Mandible discovers supported Claude, Codex, and Gemini conversations from their
provider-native files. A session need not be launched by Mandible to appear or
to participate in work. Managed Console sessions can offer additional process
controls or structured events. See [Agent integration](/docs/concepts/agent-tiers).

For an external command, `mandible wrap` can register process and terminal
navigation information while preserving terminal I/O:

```bash
mandible wrap -- claude
mandible wrap -- codex exec "fix the bug"
```

Agents of every provider reach the ledger through the `mandible` command.
Local calls identify the agent by its provider/session or managed app/session
claim. See [Local client access](/docs/local-client-access)
for the transport and identity contract.
